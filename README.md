# 📁 Интерактивный справочник лицензий управляющих компаний

Онлайн-справочник по Реестру лицензий управляющих компаний Банка России. Справочник создан на основе официального машиночитаемого снимка.

🌐 Сайт: [https://prog815.github.io/uk-licenses-registry/](https://prog815.github.io/uk-licenses-registry/)

Этот справочник — для инвесторов, юристов, комплаенс-специалистов, аналитиков финансового рынка и сотрудников служб безопасности. Главная задача — помочь быстро проверить, действует ли лицензия управляющей компании на управление инвестиционными фондами, ПИФ и НПФ, и **совпадает ли сайт, на котором предлагают услуги УК, с адресом, указанным в реестре**.

---

## Что кодирует реестр лицензий управляющих компаний

**Реестр лицензий управляющих компаний** — официальный перечень лицензий, выданных Банком России на осуществление деятельности по управлению инвестиционными фондами, паевыми инвестиционными фондами и негосударственными пенсионными фондами. Он отвечает на вопросы: **«Действует ли лицензия этой УК?»**, **«Совпадает ли её сайт с указанным в реестре?»** и **«Когда была выдана или аннулирована лицензия?»**.

В текущем снимке справочника содержится **1 172 записи**, из которых:
- **361 действующая** лицензия (все со сроком действия «Бессрочно»);
- **811 аннулированных** лицензий (с указанием даты прекращения и/или даты аннулирования).

Структура реестра **плоская** — одна лицензия, одна запись. Карточка содержит:
- Номер лицензии (уникальный идентификатор, используется для прямых ссылок);
- ОГРН и ИНН управляющей компании;
- Полное и сокращённое наименование;
- Вид лицензируемой деятельности;
- Дату выдачи лицензии и срок действия;
- Для аннулированных — дату прекращения действия и дату аннулирования;
- Адрес в пределах места нахождения (по данным ЕГРЮЛ);
- **Официальные сайты** (полные URL) и нормализованные **домены** (для поиска);
- Контактные телефоны и электронную почту.

> **Важно про несколько лицензий на одну компанию.** У одной управляющей компании может быть несколько лицензий в реестре: текущая действующая и исторические, выданные ранее. В выгрузке ЦБ они хранятся отдельными записями. Поиск по ОГРН компании показывает все её лицензии — и действующие, и аннулированные. В текущем снимке таких компаний — 214 (например, ООО УК «ФинанСист» имеет 2 аннулированные лицензии: № 21-000-1-00547 и № 21-000-1-00113).

> **Важно про другие финансовые организации.** Управляющая компания управляет активами фондов, но не даёт индивидуальных инвестиционных рекомендаций (для этого нужен инвестиционный советник) и не является страховщиком (отдельный реестр ССД). Если вам нужно проверить сам ПИФ, страховую компанию, МФО или ломбард, используйте соответствующие справочники экосистемы.

## Для кого и зачем

Справочник пригодится, если вам нужно:
- **проверить УК перед доверием ей денег** — убедиться, что её лицензия действует, особенно если услуги предлагают в рекламе, мессенджерах или соцсетях;
- отличить настоящий сайт управляющей компании от мошеннического сайта-двойника;
- узнать, когда была выдана лицензия и действует ли она бессрочно;
- для аннулированных лицензий — увидеть дату прекращения действия и дату решения об аннулировании;
- найти ИНН или ОГРН компании для сверки договора доверительного управления;
- увидеть все исторические лицензии компании (для компаний, менявших лицензии).

## Возможности интерфейса

- **Мгновенный поиск.** Результаты появляются по мере ввода — без кнопки «Найти».
- **Поиск по реквизитам и домену.** Введите название компании, ИНН, ОГРН, номер лицензии, адрес сайта, телефон или email. **Поиск по домену** работает строго: домен сравнивается **целиком**, поэтому `tn-invest.ru` не совпадёт с `tn-invest.ru.example.com`. Это защищает от ложных совпадений при проверке ссылок из рекламы и мессенджеров.
- **Поиск по ссылке целиком.** Можно вставить полный адрес страницы — поиск найдёт УК по нормализованному адресу сайта.
- **Один фильтр.** Выпадающий список по **Статусу** (Действующая / Аннулированная / Все статусы). По умолчанию показываются только действующие — так как аннулированных в реестре в 2,25 раза больше (361 к 811).
- **Копирование в один клик.** Клик по бейджу с номером лицензии копирует его в буфер обмена. Внизу экрана появится подтверждение.
- **Бейджи статуса и плашка аннулирования.** Цветной бейдж показывает статус лицензии. У аннулированных выводится **красный блок** с одной из трёх формулировок:
  - «Дата принятия решения об аннулировании: {дата}» — если дата аннулирования есть;
  - «Дата прекращения действия лицензии: {дата}. Дата решения об аннулировании в выгрузке не указана» — если есть только дата прекращения;
  - «Даты прекращения и аннулирования в выгрузке не указаны» — редкий случай.
- **Прямые ссылки на сайты.** Клик по чипу с URL сайта открывает его в новой вкладке.
- **Поделиться карточкой.** Кнопка `📤 Поделиться` формирует полный текст с реквизитами лицензии и ссылкой на карточку.
- **Прямые ссылки на карточки.** Каждую лицензию можно передать через `?code=…` в адресе (по номеру лицензии). Ссылка сразу находит запись и подсвечивает её.
- **Подсветка совпадений.** Искомые слова и цифры выделяются прямо в тексте карточки.

## Примеры запросов

- `Транснефть` — найдёт ООО УК «Транснефть Инвест».
- `21-000-1-00735` — откроет карточку по номеру лицензии Транснефть Инвест.
- `tn-invest.ru` — найдёт компанию по домену сайта.
- `1097746845679` — найдёт компанию по её ОГРН.
- `0278087082` — найдёт компанию по ИНН с ведущим нулём (ООО УК «ФинанСист»).
- `info@ukmik.ru` — найдёт ООО «УК «Михайловский» по адресу электронной почты.
- `ФинанСист` — найдёт обе аннулированные лицензии компании (2 карточки).
- `Бессрочно` — найдёт все 361 действующую лицензию (у всех этот срок действия).

**Популярные фильтры:**
- **Действующая** — УК с действующей лицензией (361 запись);
- **Аннулированная** — лицензии, которые были аннулированы Банком России (811 записей, с указанием дат).

## Прямые ссылки на коды

Каждую карточку можно открыть напрямую по номеру лицензии — например:
- `https://prog815.github.io/uk-licenses-registry/?code=21-000-1-00735` — откроет карточку ООО УК «Транснефть Инвест» (действующая, бессрочная).
- `https://prog815.github.io/uk-licenses-registry/?code=21-000-1-00547` — откроет карточку ООО УК «ФинанСист» (аннулирована 14.11.2019).
- `https://prog815.github.io/uk-licenses-registry/?code=21-000-1-00113` — откроет предыдущую лицензию ООО УК «ФинанСист» (аннулирована, дата решения об аннулировании в выгрузке не указана).

Ссылка с `?code=` сразу находит запись с этим номером лицензии и подсвечивает её.

## Источник и актуальность

- **Источник:** машиночитаемый снимок открытых данных Банка России ([официальный сайт](https://www.cbr.ru/)).
- **Обозначение:** Реестр лицензий управляющих компаний на осуществление деятельности по управлению инвестиционными фондами, паевыми инвестиционными фондами и негосударственными пенсионными фондами.

Данные обновляются автоматически **каждый день**. Точная дата актуальности текущего снимка и статистика по количеству записей всегда видны **внизу страницы** на самом сайте.
